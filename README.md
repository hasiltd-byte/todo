# TODO — Candy & Convenience Shop

אתר One Page בעברית וב-RTL עבור TODO בקניון נחמיה. נבנה על בסיס המבנה הטכני של אתר האיפור שסופק כ-reference, אבל עם עיצוב ותוכן חדשים שמתאימים לחנות ממתקים / נוחות / בלונים / מתנות / שתייה.

## טכנולוגיה

- Next.js 16.3.6
- React 19.3
- TypeScript
- App Router
- lucide-react
- ללא Tailwind וללא מסד נתונים

## הרצה

```bash
npm install
npm run dev
```

ואז לפתוח:

```text
http://localhost:3000
```

## לפני העלייה לאוויר — חשוב

פתחו את `lib/site.ts` ועדכנו:

- `phoneDisplay` — מספר הטלפון המוצג, לדוגמה `050-123-4567`
- `phoneInternational` — מספר WhatsApp בפורמט בינלאומי ללא `+` וללא מקפים, לדוגמה `972501234567`
- `whatsappText` — הודעת WhatsApp ברירת מחדל
- `locationName` אם רוצים ניסוח מיקום אחר

כל עוד אין מספר WhatsApp, כפתורי הקשר יורידו לאזור יצירת הקשר, והטופס יציג הודעת תזכורת למפתח במקום לשלוח למספר שגוי.

## תוכן / עיצוב

האתר כולל:

- פס הודעה עליון + Header sticky
- Hero צבעוני עם איורי CSS מקוריים (ללא תלות בתמונות סטוק)
- קטגוריות: ממתקים, שתייה, אלכוהול 18+, בלונים, מתנות ופיצוחים
- אזור ימי הולדת
- סיפור החנות והזמנה של אדיר רווח
- אזור FAQ
- טופס WhatsApp מוכן לחיבור לאחר הזנת מספר
- עיצוב Responsive מלא למובייל / טאבלט / דסקטופ
- מטא-דאטה בסיסי ל-SEO

## התאמות מומלצות לאחר קבלת חומר מהלקוח

1. להוסיף מספר טלפון ו-WhatsApp אמיתי.
2. להוסיף שעות פתיחה מדויקות.
3. להחליף חלק מהאיורים בתמונות מקוריות של החנות והמוצרים, אם יש.
4. להוסיף קישור Google Maps מדויק לאחר שיש Pin/כתובת מלאה.
5. אם יש Instagram/Facebook — להוסיף קישורים בפוטר.
6. לאחר בחירת דומיין — להוסיף `metadataBase`, canonical, sitemap ו-Search Console.
